# breast-cancer-data-mining
# Unsupervised Learning in Breast Cancer Diagnosis

## Overview

Academic project developed during my Erasmus+ year at Wrocław University of Science and Technology, within the MSc programme in Applied Mathematics.

The aim of this project is to explore the application of unsupervised machine learning techniques to medical data, identifying underlying patterns in breast tumour samples without using diagnostic labels during training.

## Dataset

Wisconsin Diagnostic Breast Cancer Dataset — UCI Machine Learning Repository.

- 569 observations
- 30 numerical features
- Two diagnostic classes: benign and malignant

## Methodology

- Data preprocessing and standardization
- Principal Component Analysis (PCA)
- K-means clustering
- Agglomerative hierarchical clustering (AGNES)
- Silhouette analysis
- Dendrograms and data visualization

## Results

The first two principal components retained approximately 63% of the original variance.

Both clustering algorithms achieved silhouette scores above 0.50, showing meaningful group structures and partial alignment with the actual diagnostic classes.

## Technologies

Python, Pandas, NumPy, Scikit-learn, SciPy, Matplotlib, Seaborn and Jupyter Notebook.
